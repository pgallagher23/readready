Make a PDF accessible

Turn untagged PDFs into WCAG 2.1 AA compliant accessible documents. The original page layout stays intact, while an added structure layer lets screen readers navigate by headings, tables, and links and hear descriptions of images.

1. Upload

Choose one or more PDF files. Text-based and scanned documents are both supported; scanned pages are read with optical character recognition.

2. Review

When processing finishes, the results panel lists what was fixed and what still needs a person: image descriptions, heading levels, reading order, and table structure can all be checked and edited.

3. Download

Download the tagged accessible PDF together with an accessibility report. Automated checks are not a substitute for testing with assistive technology, so review the report before you publish.
